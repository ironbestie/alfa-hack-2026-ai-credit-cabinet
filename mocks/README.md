# Моки внешних сервисов

Заглушки для ЕГРЮЛ, ФНС, БКИ, данных банка, SMS и выдачи. Отвечают по ИНН заранее подготовленными данными, а на нескольких ИНН специально тормозят или падают, чтобы показать на демо, как конвейер переживает сбои. Все компании и цифры выдуманные.

Работает на WireMock: ответы лежат в `__files`, правила сопоставления запросов в `mappings`.

## Запуск

Добавить в `docker-compose.yaml` сервис из `docker-compose.mocks.yaml` и поднять:

```bash
docker compose up -d mocks
```

Или отдельно:

```bash
docker run --rm -p 8089:8080 -v "$PWD/mocks:/home/wiremock" wiremock/wiremock:3.9.1
```

Из бэкенда внутри compose моки доступны по `http://mocks:8080`, с хоста по `http://localhost:8089`.

## Эндпоинты

| Сервис | Запрос |
|---|---|
| ЕГРЮЛ | `GET /egrul/v1/companies/{inn}` |
| ФНС | `GET /fns/v1/companies/{inn}/finance` |
| БКИ | `POST /bki/v1/reports`, тело `{"inn": "...", "consentId": "..."}` |
| Банк | `GET /bank/v1/clients/{inn}` |
| SMS | `POST /sms/v1/send` |
| Выдача | `POST /payments/v1/disbursements` |

Без `consentId` БКИ вернёт 403: запрашивать кредитную историю без согласия нельзя. SMS всегда отвечает `SENT`, код на демо 1234. Выдача отвечает через 2 секунды.

Последние семь компаний совпадают с синтетическими клиентами Марины, ИНН заменены на выдуманные с правильными контрольными суммами.

На любой другой ИНН ЕГРЮЛ и ФНС отвечают 404, а банк говорит, что это не его клиент.

Сценарий с ФНС запоминает, сколько раз его уже вызвали. Перед прогоном демо его надо сбросить:

```bash
curl -X POST http://localhost:8089/__admin/scenarios/reset
```

## Откуда брать поля для скоринга

| Поле | Где лежит |
|---|---|
| возраст бизнеса | ЕГРЮЛ, `registrationDate` |
| ОКВЭД | ЕГРЮЛ, `okved.code` |
| статус компании | ЕГРЮЛ, `status` |
| выручка | ФНС, `revenue` |
| налоговый долг | ФНС, `taxDebt` |
| приостановка операций | ФНС, `accountsSuspended` |
| общий долг | БКИ, `totalDebt` |
| худшая просрочка | БКИ, `maxOverdueDays24m` |
| число кредитов | БКИ, длина `activeLoans` |
| сколько месяцев в банке | Банк, `relationshipMonths` |

## Быстрая проверка

```bash
curl http://localhost:8089/egrul/v1/companies/7703168426
curl http://localhost:8089/fns/v1/companies/7704983159/finance
curl -X POST http://localhost:8089/bki/v1/reports -H "Content-Type: application/json" -d '{"inn":"7703168426","consentId":"demo"}'
curl http://localhost:8089/bank/v1/clients/7704983159
```

Чтобы добавить компанию, скопируйте её файлы из `__files` и правила из `mappings` под новым ИНН и перезапустите контейнер.
