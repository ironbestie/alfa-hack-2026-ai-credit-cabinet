# Мок-сервисы внешних источников

Заглушки ЕГРЮЛ/ЕГРИП, ФНС («Прозрачный бизнес»), БКИ, внутренних данных банка, SMS и выдачи денег. Они отвечают по ИНН так, как отвечали бы настоящие сервисы, включая задержки и сбои. Данные синтетические.

Сделано на WireMock: логики в коде нет, каждый ответ описан JSON-файлом.

## Как подключить

1. Положить папку `mocks/` в корень репозитория.
2. Добавить сервис в `docker-compose.yaml` (готовый кусок лежит в `docker-compose.mocks.yaml`):

```yaml
  mocks:
    image: wiremock/wiremock:3.9.1
    ports:
      - "8089:8080"
    volumes:
      - ./mocks:/home/wiremock
    command: ["--verbose"]
```

3. В `application.yaml` бэкенда указать адрес: внутри compose `http://mocks:8080`, с ноутбука `http://localhost:8089`.

## Эндпоинты

| Сервис | Запрос | Что отдаёт |
|---|---|---|
| ЕГРЮЛ | `GET /egrul/v1/companies/{inn}` | название, ОГРН, статус, дата регистрации, ОКВЭД, категория МСП, руководитель |
| ФНС | `GET /fns/v1/companies/{inn}/finance` | выручка, прибыль, налоговый долг, приостановка операций по счетам |
| БКИ | `POST /bki/v1/reports` с телом `{"inn": "...", "consentId": "..."}` | действующие кредиты, общий долг, просрочки, запросы за 30 дней |
| Банк | `GET /bank/v1/clients/{inn}` | клиент ли банка, сколько месяцев, поступления по месяцам |
| SMS | `POST /sms/v1/send` | всегда `SENT`; код генерирует бэкенд, в демо 1234 |
| Выдача | `POST /payments/v1/disbursements` | через 2 секунды `COMPLETED` |

БКИ без поля `consentId` отвечает 403 `CONSENT_REQUIRED`: по 218-ФЗ кредитную историю нельзя запросить без согласия.

## Как бэкенд берёт поля для скоринга

| Поле скоринга | Откуда |
|---|---|
| возраст бизнеса, мес. | ЕГРЮЛ `registrationDate` |
| ОКВЭД | ЕГРЮЛ `okved.code` |
| выручка | ФНС `revenue` |
| налоговый долг | ФНС `taxDebt` |
| общий долг | БКИ `totalDebt` |
| худшая просрочка, дней | БКИ `maxOverdueDays24m` |
| число кредитов | БКИ: длина `activeLoans` |
| месяцев в банке | Банк `relationshipMonths` |
| стоп-факторы | ЕГРЮЛ `status`, ФНС `accountsSuspended`, БКИ `maxOverdueDays24m` от 90 |

## Проверка

```bash
docker compose up -d mocks
curl http://localhost:8089/egrul/v1/companies/7703168426
curl http://localhost:8089/egrul/v1/companies/7718046237
curl http://localhost:8089/fns/v1/companies/7704983159/finance
curl -X POST http://localhost:8089/bki/v1/reports -H "Content-Type: application/json" -d '{"inn":"7703168426","consentId":"demo"}'
curl -X POST http://localhost:8089/bki/v1/reports -H "Content-Type: application/json" -d '{"inn":"7703168426"}'
curl http://localhost:8089/bank/v1/clients/7704983159
```

Перед каждым прогоном демо сбросить сценарий «ФНС падает дважды»:

```bash
curl -X POST http://localhost:8089/__admin/scenarios/reset
```

## Как поменять данные

Ответы лежат в `__files/<сервис>/<ИНН>.json`, правила сопоставления в `mappings/<сервис>.json`. Чтобы добавить компанию, скопируйте файлы любой из готовых и поправьте ИНН в обоих местах. После правок перезапустите контейнер: `docker compose restart mocks`.
